# Stablecoin Analysis Visualization

This directory contains scripts for analyzing stablecoin transaction data and creating visualizations.

## Files

- `stats.py` - Main script that extracts stablecoin transfer data from Ethereum blockchain
- `visualize_stablecoins.py` - Creates plots from the CSV data generated by stats.py
- `requirements.txt` - Python dependencies

## Usage

### 1. Extract Data
First, run the stats.py script to extract stablecoin transfer data:

```bash
# Analyze all stablecoins
python stats.py --all

# Or analyze specific stablecoins
python stats.py --usdc --usdt --dai
```

This will generate CSV files for each stablecoin:
- `{stablecoin}_daily_stats.csv` - Daily aggregated statistics
- `{stablecoin}_transfers.csv` - Individual transfer records

### 2. Create Visualizations
After running stats.py, create the plots:

```bash
python visualize_stablecoins.py
```

This will generate two PNG files:
- `stablecoin_volume_plot.png` - Daily transaction volume for all stablecoins
- `stablecoin_transaction_count_plot.png` - Daily transaction count for all stablecoins

## Generated Plots

### Volume Plot
- **X-axis**: Days
- **Y-axis**: Transaction volume (number of tokens transacted)
- **Features**: Different colors for each stablecoin, legend, formatted axes

### Transaction Count Plot  
- **X-axis**: Days
- **Y-axis**: Number of transactions
- **Features**: Different colors for each stablecoin, legend, formatted axes
